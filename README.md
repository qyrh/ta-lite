# 教学助手 · 轻量网页版

在线版：<https://qyrh.github.io/ta-lite/>

给同事用的一份“不依赖某位老师电脑”的轻量工具：**试卷收集/分析、教案（含试听课）、进度表→计划、反馈模板与提示词**。
纯静态页面，可以放 GitHub Pages / 任意静态空间，也可以直接本地打开；不需要租服务器，不需要装 Electron。

## 它不做什么

- 不建学生档案：姓名、年级、课题都是临时字段，缺省用“同学 / 本次测试”，AI 不编造。
- 不上传文件到本站：试卷图片只在浏览器里压缩，然后直连 AI 官方接口（或你们自己的团队代理）。
- 不替代完整版教学助手：完整版里的题库、教参索引、四表、课表、视频产线不在这里。

## 三种用法

### A. 本地打开（最快验证）

```powershell
cd web-lite
python -m http.server 8899 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8899`。设置里填自己的 DeepSeek Key 即可。
这是“本地安装”的轻量形态：双击一个启动脚本 + 浏览器，不依赖 Electron。

### B. GitHub Pages（推荐给同事）

1. 在 GitHub 新建一个仓库（public 即可；页面里没有任何 Key）。
2. 把 `web-lite/` 里的全部文件上传到仓库根目录（或 `docs/`）。
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
4. 等 1 分钟，访问 `https://你的用户名.github.io/仓库名/`。

同事打开网址 → 设置里填 **自己的 Key**（方式 1），或者填 **团队代理地址 + 访问口令**（方式 2）。

### C. 团队代理（同事不用配 Key）

如果希望“所有同事共用一个 Key、但浏览器拿不到 Key”，部署同目录的 `worker/` 到 Cloudflare Workers（免费）：

```powershell
cd web-lite/worker
npx wrangler login
npx wrangler deploy
npx wrangler secret put ACCESS_TOKEN
npx wrangler secret put DEEPSEEK_API_KEY
```

然后把 Worker 地址和访问口令发给同事，在网页“设置 → 团队代理”里填。
详见 `worker/README.md`。不需要服务器，Cloudflare 免费额度够小团队。

## 三种接入方式怎么选

| 方式 | 同事要做什么 | Key 在哪 | 适合 |
|---|---|---|---|
| 每人自己的 Key | 各自填一次 DeepSeek Key | 各自浏览器 localStorage | 人少、各付各的 |
| 团队代理 | 填代理地址 + 访问口令 | Cloudflare Worker Secret | 团队共用、不想让浏览器碰 Key |
| 本地模式 | 打开本地静态服务 | 各自浏览器 | 临时用、内网 |

> 直接 Key 模式：Key 只存在当前浏览器的 localStorage，页面代码和站点里没有 Key。
> 团队代理模式：浏览器只拿访问口令；真实 Key 在 Worker Secret，错误信息也会脱敏。
> 不要把 Key 写进 GitHub 仓库、截图或群聊。共用电脑建议用无痕窗口，用完清理站点数据。

## 功能

### 试卷收集 / 试卷分析
- 上传图片或 PDF（最多 10 页）；PDF 在浏览器里转图片。
- 识图模型逐页提取：题号、题干、答案、学生作答、对错、得分、满分、知识点、错因、解析。
- 结果表格可直接改；统计题数/正确/错误/得分率。
- AI 分析（总体判断 / 得分结构 / 错因归类 / 重点补漏 / 下节课建议 / 家长版三句话），也可用本地规则生成。
- 导出 `试卷分析报告.docx`、`错题清单.docx`；打印/存 PDF。
- 没有试卷图片时，可直接粘成绩表做分布分析。

### 教案（含试听课）
- 新授课 / 复习课 / 试听课三种结构。
- 已知信息填多少算多少；缺的用【待补】，AI 不编造成绩/排名。
- 生成后可逐段改；导出 Word；存草稿（本浏览器）。
- 试听课结构含：破冰、学情探测、体验探究、成果展示、家长沟通、转化建议。

### 进度表 → 学习计划
- 粘贴已有进度表/上到哪了、可用课时、目标，生成分阶段计划。
- 输出：现状判断、目标拆解、阶段安排表、前四次课、检测与调整、家长沟通要点。
- 可导出 Word；不建学生档案。

### 反馈模板与提示词
- 内置 5 个模板：课后反馈、阶段总结、试听转化、家长沟通、续费规划。
- 占位符：`{学生}` `{课题}` `{表现}` `{问题}` `{下一步}` `{家长诉求}` `{老师}`。
- 两种用法：AI 生成（更自然） / 直接套模板（不调 AI 也能用）。
- 模板可新建、编辑、删除；只存本浏览器；可导出数据 JSON。

### 设置 / 数据
- 接入方式：每人自己的 Key / 团队代理。
- 供应商：DeepSeek / 智谱 GLM；模型和识图模型可改。
- 测试连接；导出/导入数据；清空本浏览器数据。
- 所有草稿、模板、结果存 `localStorage`；换电脑用“导出数据 JSON”迁移（不含 Key）。

## 文件结构

```
web-lite/
  index.html            页面骨架
  styles.css            样式（浅色/深色、响应式、打印）
  app.js                全部业务逻辑（无构建步骤）
  lib/markdown.js       轻量 Markdown → HTML（先转义，防注入）
  lib/docx.js           浏览器端 .docx 生成（JSZip + OOXML）
  vendor/jszip.min.js   JSZip
  vendor/pdfjs/         PDF 转图片（动态加载）
  worker/index.js       Cloudflare Worker 团队代理
  worker/README.md      代理部署说明
```

## 本地自检

1. 打开页面，控制台无报错；四个页签可切换。
2. 试卷 → 填入示例 → 表格 5 行、统计正常 → 导出 .docx 能打开。
3. 教案 → 填入示例 → 生成/本地模板 → 导出 .docx 能打开。
4. 反馈 → 填入示例 → 直接套模板 → 复制/导出。
5. 设置 → 填 Key → 测试连接；再试“团队代理”填 Worker 地址/口令。
6. 刷新页面，草稿/模板/设置还在（Key 也在本浏览器；换浏览器要重填）。

## 已知边界

- 识图准确率取决于照片清晰度和模型；识别后一定要人工核对表格。
- PDF 扫描件会转图片走识图；纯文字 PDF 也可以走识图，暂未做文本层提取。
- Word 导出是 A4 宋体/黑体基础版式，复杂公式会以文本形式呈现（LaTeX 源码保留在题干里）。
- 浏览器直接调用 DeepSeek 需要其接口允许跨域；如果公司网络/浏览器拦截，改用团队代理模式。
- 没有后端，所以没有“多人实时协作/云端历史”；数据在本浏览器，靠导出 JSON 备份。
